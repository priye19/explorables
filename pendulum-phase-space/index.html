Notes

The question

If you know exactly how a pendulum starts, can you say where it will be one minute later? For a simple pendulum, yes. For a double pendulum, which is two pendulums joined end to end, the answer is no, even though its motion obeys equations with no randomness in them. This page runs each pendulum several times from starts that differ by a tiny angle Δθ, so you can see the difference.

Dynamical systems and phase space

A dynamical system is a system whose state changes with time according to a fixed rule, usually a set of differential equations. The state is the smallest set of numbers that fixes the whole future motion. For a pendulum, the state is its angle θ and its angular velocity ω = dθ/dt: knowing where it is but not how fast it moves is not enough.

Phase space is the space of all possible states. For the simple pendulum it is a plane with θ on one axis and ω on the other. As time passes, the state moves through phase space and traces a curve called a trajectory. A critical point is a state where every rate of change is zero, so a system placed exactly there stays there.

The simple pendulum

A bob hangs from a pivot on a rigid rod of length l with negligible mass. θ is the angle of the rod from the vertical. The weight mg has a part mg sin θ along the path of the bob, which pulls it back toward the bottom. With a resistance proportional to the angular velocity, Newton's second law for rotation gives the second-order ODE (ordinary differential equation):

d²θ/dt² + b dθ/dt + (g/l) sin θ = 0

g is the gravitational acceleration and b is the damping coefficient (unit 1/s), which says how strongly the resistance slows the motion. Writing ω = dθ/dt turns this into a system of two first-order ODEs, the form a computer solves:

dθ/dt = ω
dω/dt = −bω − (g/l) sin θ

The critical points are where ω = 0 and sin θ = 0: θ = 0 (hanging straight down) and θ = π (balanced straight up).

Small angles: a prediction to compare with

For small angles, sin θ ≈ θ, and the equation becomes linear: θ'' + bθ' + (g/l)θ = 0. Trying θ = eλt gives the characteristic equation and its roots (eigenvalues):

λ² + bλ + g/l = 0  ⇒  λ = −b/2 ± i ωd,   ωd = √(g/l − b²/4)

So the pendulum swings at the angular frequency ωd inside an envelope e−bt/2 that shrinks with time. With the starting values θ(0) and ω(0):

θ(t) = e−bt/2 [ θ(0) cos ωdt + ((ω(0) + bθ(0)/2) / ωd) sin ωdt ]

Tick "Show the small-angle prediction" in Settings to draw this as a dashed curve on the simple pendulum's plots, up to the present time of the run. The eigenvalues classify the critical point θ = 0, ω = 0:

  • b > 0: complex eigenvalues with a negative real part. The point is an asymptotically stable spiral: every nearby trajectory spirals into it.
  • b = 0: eigenvalues ±i√(g/l), purely imaginary. The trajectories are closed curves around the point, and the motion is periodic, with period T = 2π√(l/g) (2.006 s for l = 1 m on Earth).

The prediction is exact only for small angles. A swing that starts at θ(0) = 1 rad, released from rest without damping, takes 2.14 s instead of 2.006 s, about 7% longer, so the simulation slowly falls behind the dashed curve. At θ(0) = 0.2 rad the difference is 0.25%.

The double pendulum

A second rod of length l2 with a bob of mass m2 hangs from the first bob (mass m1, rod length l1). θ1 and θ2 are the angles of the two rods from the vertical, and ω1, ω2 their angular velocities. The equations of motion are two coupled second-order ODEs, with damping coefficients b1 and b2:

(m1+m2) l1 θ̈1 + m2 l2 θ̈2 cos(θ1−θ2) + m2 l2 θ̇2² sin(θ1−θ2) + (m1+m2) g sin θ1 + b1θ̇1 = 0
m2 l2 θ̈2 + m2 l1 θ̈1 cos(θ1−θ2) − m2 l1 θ̇1² sin(θ1−θ2) + m2 g sin θ2 + b2θ̇2 = 0

A dot means a derivative with respect to time. The state is now four numbers (θ1, ω1, θ2, ω2), so the system becomes four first-order ODEs: dθ1/dt = ω1, dθ2/dt = ω2, and the two equations above solved for the two angular accelerations. Writing Δ = θ1 − θ2 and M = m1 + m2:

dω1/dt = [ −m2l1ω1² sinΔ cosΔ − m2l2ω2² sinΔ + m2g sinθ2 cosΔ − Mg sinθ1 − b1ω1 + b2ω2 cosΔ ] / [ l1(m1 + m2 sin²Δ) ]

dω2/dt = [ Ml1ω1² sinΔ + m2l2ω2² sinΔ cosΔ + Mg sinθ1 cosΔ − Mg sinθ2 + b1ω1 cosΔ − (M/m2) b2ω2 ] / [ l2(m1 + m2 sin²Δ) ]

This page uses b1 = b2 = b (unit kg·m/s). It solves the two second-order equations as a 2 × 2 linear system for θ̈1 and θ̈2 at every time step, which gives exactly these formulas. The time stepping uses the fourth-order Runge-Kutta method with a step of 1 ms. With b = 0 no energy is lost, and the line under the picture shows that the total energy stays at its starting value, which checks the calculation.

Chaos: sensitive dependence on the start

Both systems are deterministic: the same start always gives the same motion. The difference is what happens to two starts that are almost the same. In the simple pendulum, the gap between them stays about as small as it began, or shrinks with damping. In the double pendulum at large angles, the gap grows on average exponentially,

δ(t) ≈ δ0 eλt

where δ0 is the gap at the start and λ, the Lyapunov exponent, is the average rate at which nearby trajectories separate. The gap stops growing only when it is as large as the motion itself. A system with this behaviour is called chaotic. The time for which a prediction stays within a tolerance δtol is

tp ≈ (1/λ) ln(δtol / δ0)

Because the start enters only through a logarithm, measuring it 1000 times more precisely adds only the fixed amount ln(1000)/λ to the time of a good prediction. The gap plot shows δ(t) on a logarithmic scale, where exponential growth is a straight rising line.

The double pendulum is not always chaotic. At small angles it swings in a regular pattern and nearby starts stay together. Damping also ends the chaos in time, because it removes energy until the swings are small.

What to look for

  1. Simple pendulum, default settings: both runs spiral into the critical point θ = 0, ω = 0 (the open circle in phase space), and the gap stays small. Set b = 0: the trajectory becomes a closed curve, and the motion repeats.
  2. Simple pendulum, θ(0) = 0.2, with the small-angle prediction ticked in Settings: the simulation and the dashed prediction agree. Set θ(0) = 2: the swings take longer than predicted, and the curves drift apart.
  3. Simple pendulum, ω(0) = 6.5 rad/s with b = 0 and θ(0) = 0: the pendulum goes over the top and keeps turning; ω never reaches zero. Try 6.2 rad/s: now it swings back. The boundary between the two is the curve in phase space through the point θ = π, ω = 0.
  4. Double pendulum, default settings: the two runs look identical for several seconds, then move completely differently. The gap rises along a rough straight line on the logarithmic scale before levelling off.
  5. Make Δθ 10 or 100 times smaller: the runs stay together only a few seconds longer.
  6. Double pendulum with θ₁(0) = θ₂(0) = 0.2: the motion is regular and the gap stays small. Large angles are needed for chaos.
  7. Set 10 runs: in the simple pendulum all 10 move as a tight group; in the double pendulum the group spreads across the whole picture.

Practical problem: stability and prediction

  1. Write the simple pendulum with g/l = 9.81 s⁻² and b = 0.1 s⁻¹ as a system of first-order ODEs and find its critical points.
  2. Near θ = 0, sin θ ≈ θ. Find the eigenvalues and classify the critical point θ = 0, ω = 0.
  3. Near θ = π, write θ = π + φ, so that sin θ ≈ −φ. Find the eigenvalues and classify the critical point θ = π, ω = 0.
  4. In a double pendulum the gap between two runs grows as δ(t) = δ0 eλt with λ = 2 s⁻¹. The start is known to δ0 = 10⁻³ rad. How long until the gap reaches 1 rad? How long if the start is known 1000 times more precisely?
Show the solution

(a) dθ/dt = ω and dω/dt = −0.1ω − 9.81 sin θ. Both are zero when ω = 0 and sin θ = 0, so the critical points are (θ, ω) = (0, 0) and (π, 0), and the same points shifted by whole turns 2π.

(b) The linear system is dθ/dt = ω, dω/dt = −9.81θ − 0.1ω, with matrix A = [0 1; −9.81 −0.1]. The characteristic equation det(A − λI) = 0 is λ² + 0.1λ + 9.81 = 0, so λ = −0.05 ± i√(9.81 − 0.0025) = −0.05 ± 3.132i. The eigenvalues are complex with a negative real part: an asymptotically stable spiral. The pendulum swings with angular frequency 3.132 rad/s while the swings shrink as e−0.05t.

(c) With θ = π + φ, dφ/dt = ω and dω/dt = −0.1ω − 9.81 sin(π + φ) ≈ −0.1ω + 9.81φ. The characteristic equation is λ² + 0.1λ − 9.81 = 0, so λ = (−0.1 ± √(0.01 + 39.24))/2, giving λ = 3.082 and λ = −3.182. One eigenvalue is positive and one negative: an unstable saddle point. A pendulum balanced upright falls away at the slightest disturbance.

(d) Solve δ0eλt = 1 for t: t = ln(1/δ0)/λ = ln(1000)/2 = 3.45 s. With δ0 = 10⁻⁶ rad, t = ln(10⁶)/2 = 6.91 s. A start known 1000 times more precisely gives a prediction that lasts only twice as long.
