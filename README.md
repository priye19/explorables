# Explorables

Interactive pages for engineering students. Each one runs a model in your browser: change the settings, press Play, and compare what you see with the equations from class.

**Open them here:** https://priye19.github.io/explorables/

| Explorable | Link | Subject |
|---|---|---|
| Random walk model of diffusion (1D, 2D and 3D) | https://priye19.github.io/explorables/random-walk-diffusion/ | Probability and random processes |
| Pendulum in phase space: order and chaos (simple and double pendulum) | https://priye19.github.io/explorables/pendulum-phase-space/ | Dynamical systems and differential equations |

Every explorable has the same layout: controls at the top, live results below, a Notes panel with the theory, a Settings panel for advanced options, and a light or dark mode. Nothing is loaded from the internet, so the whole repository can also be downloaded and opened offline.
